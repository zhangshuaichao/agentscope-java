# AgentScope Java 中文源码学习版

本目录为学习辅助材料，不替代上游 API 文档。源码基线为上游 `main` 的提交 `a543f993cce6e22fb37c31ae14443cf9104dbeae`，版本为 `2.1.0-SNAPSHOT`。不要把本目录描述直接套用到 1.x 或所有 2.x 发行版。

## 从哪里开始

1. [术语与概念](术语与概念.md)：先区分 Agent、模型、消息、工具、状态和运行上下文。
2. [架构与设计思想](架构与设计思想.md)：沿一次调用观察组件协作，理解接口背后的约束。
3. [源码阅读路线](源码阅读路线.md)：按问题逐步阅读，每一步都有源码入口和练习。
4. [翻译范围与验证](翻译范围与验证.md)：查当前覆盖范围、保留内容与验证限制。

## 学习版约定

- 中文注释解释原意，不改变算法、公共 API、标识符、异常消息、提示词和其他运行时字符串。
- Apache 2.0 版权与许可证头保持原文。代码示例、Javadoc 链接和标签保留可用性。
- 英文术语首次出现时保留英文名，方便搜索官方资料。
- “设计解读”是基于源码结构的解释，不冒充作者未表达的历史动机。
- 不能将“文件存在中文注释”等同于“整个项目翻译完成”。具体覆盖以清单为准。
