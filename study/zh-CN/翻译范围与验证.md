## 明确没有覆盖的内容

**Go、TypeScript/TSX、JavaScript、Python、Shell、SQL 等非 Java 源文件尚未系统中文化**，详见 [非 Java 范围说明](非Java范围说明.md)。不能把本批表述为“全仓所有源码注释完成”。

运行时提示词、日志和异常字符串没有改写。选定关键提示词（代码审查、编码代理、上下文边界与默认规则）和规范（AGENTS、CONTEXT）提供独立中文学习对照，英文原文保留；不宣称全部文档都已翻译。
