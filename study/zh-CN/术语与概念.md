# 术语与核心概念

以当前提交源码为准；链接指向仓库中的实现或接口。术语译法用于帮助理解，代码中的名称保持英文。

| 英文术语 | 中文 | 在本项目中的含义 | 源码入口 |
| --- | --- | --- | --- |
| Agent | 智能体 | 可调用、可流式输出、可观察消息的组合接口；不是模型的别名 | [Agent](../../agentscope-core/src/main/java/io/agentscope/core/agent/Agent.java) |
| ReAct | 推理—行动循环 | 模型推理决定回答或发起工具调用，工具结果回到后续推理 | [ReActAgent](../../agentscope-core/src/main/java/io/agentscope/core/ReActAgent.java) |
| Model | 模型接口 | 接受消息、工具模式和生成选项，输出 ChatResponse 流；不负责完整智能体生命周期 | [Model](../../agentscope-core/src/main/java/io/agentscope/core/model/Model.java) |
| Msg | 消息 | 对话中的完整消息对象；包含角色、内容块等，而不是一段裸字符串 | [Msg](../../agentscope-core/src/main/java/io/agentscope/core/message/Msg.java) |
| ContentBlock | 内容块 | 消息内容的统一抽象，承载文本、工具调用、工具结果或多模态内容 | [ContentBlock](../../agentscope-core/src/main/java/io/agentscope/core/message/ContentBlock.java) |
| ToolUseBlock | 工具调用块 | 记录模型请求调用的工具、参数与关联标识；请求调用不等于已经执行 | [ToolUseBlock](../../agentscope-core/src/main/java/io/agentscope/core/message/ToolUseBlock.java) |
| ToolResultBlock | 工具结果块 | 工具执行输出；需与对应调用关联，供模型继续推理 | [ToolResultBlock](../../agentscope-core/src/main/java/io/agentscope/core/message/ToolResultBlock.java) |
| AgentTool | 智能体工具 | 以名称、描述、参数模式和异步执行方法暴露外部能力 | [AgentTool](../../agentscope-core/src/main/java/io/agentscope/core/tool/AgentTool.java) |
| Toolkit | 工具集 | 组织、注册、解析和执行智能体可使用的工具 | [Toolkit](../../agentscope-core/src/main/java/io/agentscope/core/tool/Toolkit.java) |

| Mono | 单结果响应式序列 | `call` 使用 `Mono<Msg>` 表示异步终结结果；不能把它理解成同步返回的 Msg | [CallableAgent](../../agentscope-core/src/main/java/io/agentscope/core/agent/CallableAgent.java) |
| Flux | 多事件响应式序列 | 模型增量响应和执行事件流；不仅是字符串逐字输出 | [StreamableAgent](../../agentscope-core/src/main/java/io/agentscope/core/agent/StreamableAgent.java) |

| RuntimeContext | 运行上下文 | 每次调用的身份、关联 ID、属性和调用级状态引用；属性不自动持久化 | [RuntimeContext](../../agentscope-core/src/main/java/io/agentscope/core/agent/RuntimeContext.java) |
| AgentState | 智能体状态 | 对话缓冲区、摘要、轮次、权限／工具／任务子状态等可恢复信息 | [AgentState](../../agentscope-core/src/main/java/io/agentscope/core/state/AgentState.java) |
| Session | 会话 | 用于跨调用关联对话与状态的边界；不能与单次 run 或某个 Java 对象混同 | [RuntimeContext](../../agentscope-core/src/main/java/io/agentscope/core/agent/RuntimeContext.java) |
| Run | 一次执行 | 一次调用及其关联标识；同一会话可有多次执行 | [AgentRun](../../agentscope-core/src/main/java/io/agentscope/core/agent/AgentRun.java) |
| Middleware | 中间件 | 在明确的生命周期拦截点扩展行为，避免复制整个智能体实现 | [MiddlewareBase](../../agentscope-core/src/main/java/io/agentscope/core/middleware/MiddlewareBase.java) |
| Onion pattern | 洋葱模型 | 外层包装内层，调用 next 前后分别处理；构造顺序与执行顺序需要区分 | [MiddlewareChain](../../agentscope-core/src/main/java/io/agentscope/core/middleware/MiddlewareChain.java) |
| Permission | 权限决策 | 工具请求到实际执行之间的授权检查；模型想执行不代表允许执行 | [PermissionEngine](../../agentscope-core/src/main/java/io/agentscope/core/permission/PermissionEngine.java) |
| HITL | 人在回路 | 在需要人确认等边界暂停流程，接收结果后恢复，而不是假装工具已成功 | [确认与工具状态](../../agentscope-core/src/main/java/io/agentscope/core/message/ToolCallState.java) |
| Harness | 智能体运行支撑层 | 在核心循环上组合工作区、技能、记忆、子智能体、沙箱等工程能力 | [HarnessAgent](../../agentscope-harness/src/main/java/io/agentscope/harness/agent/HarnessAgent.java) |
| Workspace | 工作区 | 通过抽象访问人格、技能、记忆等文件；沙箱模式下不等于宿主机当前目录 | [工作区文档](../../docs/v2/zh/docs/harness/workspace.md) |
| Compaction | 上下文压缩 | 控制模型输入历史的大小，不等价于删除完整执行历史或训练模型 | [CompactionMiddleware](../../agentscope-harness/src/main/java/io/agentscope/harness/agent/middleware/CompactionMiddleware.java) |

## 六个最容易混淆的区别

1. **模型与智能体**：模型生成一次响应；智能体管理多步调用、工具、状态、停止与恢复。
2. **工具定义与工具执行**：schema 告诉模型“能做什么”；执行还需参数、权限、上下文及结果关联。
3. **消息与事件**：消息是对话数据；事件描述执行过程。一个终结消息前可以产生很多事件。
4. **上下文窗口与运行上下文**：前者是模型能处理的词元容量；后者是 Java 调用的身份与元数据容器。
5. **AgentState 与 RuntimeContext**：前者主要保存会话状态；后者把当前调用定位到正确会话，并携带临时属性。
6. **短期对话与长期记忆**：当前输入历史、压缩摘要、跨会话知识是不同层次，不应统称为一个 memory 列表。
