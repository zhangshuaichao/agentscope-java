# 容易误读的源码细节

以下说明基于固定源码基线，不把上游注释一概当作实现事实。这里只补注释，不修复或重构代码。

## 1. Mono.defer 不等于自动切换线程

阅读 [ToolExecutor](../../agentscope-core/src/main/java/io/agentscope/core/tool/ToolExecutor.java) 时，区分“把操作推迟到订阅时执行”和“把操作调度到另一线程”。前者是时机，后者需要具体调度算子或执行设施；返回 Mono 并不能自动使阻塞操作变成非阻塞。

## 2. 流式超时不一定是整次调用的总时限

[ModelUtils](../../agentscope-core/src/main/java/io/agentscope/core/model/ModelUtils.java) 使用 `Flux.timeout`。阅读对应重载时，应按等待信号的间隔理解，而不是把它当作整个响应流累计耗时的绝对上限。持续产出信号的流与迟迟没有下一信号的流行为不同。

## 3. 工具已执行后，状态保存失败不能撤销副作用

[ConflictPolicy](../../agentscope-core/src/main/java/io/agentscope/core/state/ConflictPolicy.java) 的 CAS 冲突可能发生在回复已流式输出、工具副作用已经发生之后。保存策略只能决定状态写入如何处理，不能自动撤销邮件、文件或外部 API 的效果。研究重试时务必同时考虑幂等性。

## 4. BYPASS 不是所有检查之前的无条件通过

[PermissionEngine](../../agentscope-core/src/main/java/io/agentscope/core/permission/PermissionEngine.java) 的实际分支顺序比模式名称更重要。BYPASS 是后面的模式回退逻辑，不能覆盖前面已经返回的拒绝、询问或工具自检结果。先按实现画出决策树，再理解枚举概述。

## 5. 采样哈希不是完整内容相等性证明

[ListHashUtil](../../agentscope-core/src/main/java/io/agentscope/core/state/ListHashUtil.java) 对大列表只采样若干位置，目的是降低检测成本。它不是完整逐项比较，也不是密码学完整性验证；不要把“哈希未变”理解为“所有元素必然未变”。

## 6. 完整读取后检查大小，不是边读取边限流

[MediaUtils](../../agentscope-core/src/main/java/io/agentscope/core/formatter/MediaUtils.java) 的远程下载路径先 `readAllBytes()` 再检查长度。大小检查能拒绝超限结果，但不能阻止此前分配读取缓冲区。此处只是明确执行顺序，本学习版不改变该行为。

## 7. 声明扩展点与实现方法是两件事

[MiddlewareBase.activePoints](../../agentscope-core/src/main/java/io/agentscope/core/middleware/MiddlewareBase.java) 决定参与点。以 [GracefulShutdownMiddleware](../../agentscope-core/src/main/java/io/agentscope/core/shutdown/GracefulShutdownMiddleware.java) 为例，原类概述涉及 onAgent，但实际参与点应以 `activePoints()` 和实现方法为准，不能只读开头段落。

## 8. 旧版本 API 文档可能不是当前事件路径

[GenericRAGHook](../../agentscope-core/src/main/java/io/agentscope/core/rag/GenericRAGHook.java) 仍有历史 PreReasoningEvent 描述，实际 `onEvent` 检查的是 PreCallEvent。这个包本身带弃用兼容信息。学习 v2 时先沿当前入口，再把 legacy hook 当作迁移兼容层阅读。

## 9. 防御性列表副本不是元素深拷贝

[AgentState.getContext](../../agentscope-core/src/main/java/io/agentscope/core/state/AgentState.java) 复制列表并包装为不可修改视图；它避免通过返回列表直接增删原列表，但不意味着复制了每个 Msg 对象的整个对象图。`contextMutable()` 则明确返回真实可变列表。

## 10. Token 使用量细分不能重复相加

[ChatUsage](../../agentscope-core/src/main/java/io/agentscope/core/model/ChatUsage.java) 中缓存、推理等细分统计需要结合其所属总量理解。把总量与已包含的子集再相加会重复计数。展示成本或性能数据前，应核对服务商返回字段的实际语义。

## 11. 执行观察记录不是普通日志

[ActionObserver](../../agentscope-core/src/main/java/io/agentscope/core/observation/ActionObserver.java) 明确要求确认持久化边界；[ActionObservation](../../agentscope-core/src/main/java/io/agentscope/core/observation/ActionObservation.java) 的 RETURNED 仅表示执行尝试返回，不直接等于业务成功。不要把观察失败随意转成“可以安全重试工具”。

## 12. 模型 API 兼容不等于行为兼容

[Model](../../agentscope-core/src/main/java/io/agentscope/core/model/Model.java) 单独区分原生结构化输出、与工具同时使用的能力，以及强制指定工具能力。默认回退值不同，是为了避免对未知服务商发送不受支持的强约束。


## 13. 文件总线的接口语义，不等于具体后端的原子消费保证

[WorkspaceMessageBus.queueDrain](../../agentscope-harness/src/main/java/io/agentscope/harness/agent/bus/WorkspaceMessageBus.java) 实际顺序是列目录、读取、删除，没有原子认领或跨进程互斥。共享文件后端可让不同进程看见消息，不自动意味着多个消费者不会同时读到同一项。`publish` 是空操作，`subscribe` 产生定时空信号，靠调用方再读取持久化队列或日志，不能把它当作携带消息正文的原生推送。

## 14. Redis 单值 CAS 不覆盖整个列表或会话事务

[RedisAgentStateStore](../../agentscope-extensions/agentscope-extensions-redis/src/main/java/io/agentscope/extensions/redis/state/RedisAgentStateStore.java) 的单值保存调用 Lua 版本写入，而列表保存分步读取长度、比较采样哈希、重建或追加、更新哈希和键索引。两条路径的原子边界不同。V1 哈希标签解决相关状态键落在同一 Redis Cluster 槽的问题，不代表把多步业务流程合成事务，也不自动迁移 V0 数据。

## 15. 租约过期不会终止旧执行者

[RedisSandboxExecutionGuard](../../agentscope-extensions/agentscope-extensions-redis/src/main/java/io/agentscope/extensions/redis/sandbox/RedisSandboxExecutionGuard.java) 用 `SET NX PX` 领取租约，用令牌比较后删除避免误解锁。当前实现没有自动续租或 fencing token；旧执行仍在运行而 TTL 到期时，新调用可进入。同理，[StoreBackedPeriodicGate](../../agentscope-harness/src/main/java/io/agentscope/harness/agent/coordination/StoreBackedPeriodicGate.java) 记录的是“领取时间”，不是“任务成功时间”。这些都是执行资格的协调机制，不是外部副作用的回滚或完成证明。

## 16. 晋级 API 不表示自动跳过批准

[HarnessAgent.promoteSkill](../../agentscope-harness/src/main/java/io/agentscope/harness/agent/HarnessAgent.java) 转发给晋级器；[SkillPromoter](../../agentscope-harness/src/main/java/io/agentscope/harness/agent/skill/curator/SkillPromoter.java) 仍然经过配置的审批门。调用入口与审批证据是两件事。研究自主学习技能时，分别检查扫描、批准、发布和索引写入，不把“找到可用文件”当成安全证明。

## 17. 示例控制器的路径校验，不应按旧注释想象

[AgentWorkspaceController.validateRelPath](../../agentscope-examples/agents/agentscope-dataagent/src/main/java/io/agentscope/dataagent/web/api/AgentWorkspaceController.java) 实际先把反斜杠换成斜杠，再移除首尾斜杠，拒绝空段、`.` 与 `..`。它不是“拒绝所有绝对路径及所有点开头名称”：`.hidden` 会通过，`/file` 会变成 `file`。底层文件系统的路径隔离和符号链接边界仍需分别检查，不能把字符串检查当成完整沙箱证明。

## 18. 原子文件替换，不代表配置与运行态一起提交

[BindingPersistence.mutate](../../agentscope-examples/agents/agentscope-dataagent/src/main/java/io/agentscope/dataagent/web/api/BindingPersistence.java) 的顺序是进程内锁、读配置、修改、原子移动覆盖文件、尝试更新渠道。渠道热更新失败仅记日志，不撤销已经写入的文件；锁也不能协调另一个进程。学习配置热更新时应区分“磁盘已保存”“运行中已应用”和“下一次启动生效”三种状态。

## 19. SSE 接口名称不证明逐 token 流式，也不证明首轮工具事件齐全

[ChatController.stream](../../agentscope-examples/agents/agentscope-dataagent/src/main/java/io/agentscope/dataagent/web/api/ChatController.java) 等完整回复得到后才发一个 `token` 事件，再发 `done`；它不是直接转发模型增量 token。工具事件订阅在开始时仅查一次已存在的存储会话键，找不到就使用空流。原注释描述“每个事件到来时重新按 gateKey 查找”的回退策略，但当前实现没有该策略：首轮仍会执行聊天，却可能没有这条工具事件观察流。

## 20. 同源请求不等于 HTTPS，生成临时密码的方法不负责配置 TLS

[AdminUserController.generateTempPassword](../../agentscope-examples/agents/agentscope-dataagent/src/main/java/io/agentscope/dataagent/web/api/AdminUserController.java) 的职责是生成临时密码；创建响应返回明文密码一次。原注释关于 HTTPS 的说法不是该方法提供的保证。同源只约束来源关系，不保证加密传输；部署入口及日志配置必须另外审查。这些说明纠正学习材料，不修改原业务行为。
