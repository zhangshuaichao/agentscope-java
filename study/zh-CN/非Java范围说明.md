## 文档与提示词

当前提供的是选定关键规范和提示词的**中文学习对照**，不是覆盖全部 Markdown 的机械翻译。英文原文、可执行提示词、日志、异常消息、SQL、JSON/YAML 值和测试样例字符串保持不变。上游已经提供的中文文档直接链接复用。

如继续扩展，建议按学习目的分层：先前端 API 对照，再控制平面 Go 服务，最后脚本与模式文件。不同语言需要对应的语法/词元保护验证，不能沿用 Java 注释剥离器后就宣称代码行为不变。生成文件应优先解释其来源，而非直接改写后被重新生成覆盖。
